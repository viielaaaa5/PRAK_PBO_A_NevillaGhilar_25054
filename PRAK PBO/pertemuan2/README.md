## 1. Ringkasan Soal

Praktikum ini membahas pembuatan kelas `Mahasiswa` untuk menyimpan data mahasiswa berupa NIM, nama, dan nilai. Program dibuat menggunakan Java dan PHP dengan menerapkan konsep kelas, objek, constructor, dan enkapsulasi.

Hal yang dikerjakan dalam praktikum ini:

1. Membuat objek mahasiswa dengan data NIM dan nama.
2. Menggunakan constructor untuk mengisi data saat objek dibuat.
3. Menggunakan atribut dan method untuk mengelola data mahasiswa.
4. Menerapkan enkapsulasi agar data dapat dikelola melalui method yang tersedia.

---

## 2. Implementasi Java
Yang saya kerjakan:

- Membuat kelas `Mahasiswa` untuk menyimpan data mahasiswa.
- Menambahkan atribut untuk menyimpan identitas mahasiswa.
- Menggunakan constructor untuk mengisi data ketika objek dibuat.
- Menggunakan method untuk menampilkan atau mengakses data mahasiswa.
- Menerapkan enkapsulasi agar pengelolaan data lebih terstruktur.

---

## 3. Implementasi PHP
Implementasi PHP menggunakan konsep yang sama dengan Java, tetapi sintaksnya berbeda.

Yang saya kerjakan:

- Membuat kelas `Mahasiswa` untuk menyimpan data mahasiswa.
- Menggunakan constructor untuk mengisi data saat objek dibuat.
- Membuat method untuk mengelola dan menampilkan data.
- Menerapkan enkapsulasi agar data dikelola melalui bagian kelas yang sesuai.
